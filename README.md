# Librería de Números Complejos en Python

## Descripción

Este proyecto implementa una librería en Python para realizar operaciones con números complejos sin utilizar el tipo de dato `complex` proporcionado por Python.

# Objetivos

- Implementar una librería reutilizable.
- No utilizar el tipo `complex` de Python.
- Implementar pruebas automáticas utilizando `unittest`.
- Aplicar buenas prácticas de programación y control de versiones con Git.

---

# Funciones implementadas

La librería incluye las siguientes funciones:

1. Suma de números complejos.
2. Resta de números complejos.
3. Multiplicación de números complejos.
4. División de números complejos.
5. Cálculo del módulo.
6. Conjugado.
7. Conversión de coordenadas cartesianas a polares.
8. Conversión de coordenadas polares a cartesianas.
9. Obtención de la fase de un número complejo.
